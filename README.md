# Java Practice

Javaの学習・練習用リポジトリです。
基礎文法から始めて、オブジェクト指向やアルゴリズムの理解を深めながら、
日々の学習内容や書いたコードをここに記録していきます。
エラーを解決した過程や気づいたポイントもメモとして残し、
将来的なソフトウェア開発に活かせる知識・実装力を身につけることを目指します。


## Purpose

- Javaの基本文法を学習する
- 練習コードを記録する
- コンパイルと実行の仕組みを学ぶ
- Git / GitHubの操作に慣れる
- オブジェクト指向プログラミングの考え方を身につける
- エラーメッセージの読み方・デバッグ方法を習得する
- アルゴリズムや基本的なデータ構造への理解を深める
- 学んだ内容をコードとメモとして継続的に蓄積する
- 将来的なソフトウェア開発につなげる


## Contents

- 変数・データ型（int, double, String, boolean など）
- 演算子（算術・比較・論理演算子）
- 条件分岐（if / else if / switch）
- 繰り返し処理（for / while / do-while）
- 配列・多次元配列
- コレクション（ArrayList, HashMap など）
- メソッドの定義・引数・戻り値
- クラスとオブジェクト指向の基礎（フィールド・コンストラクタ）
- 継承・ポリモーフィズム・インターフェース
- 例外処理（try / catch / finally）
- 入出力処理（Scannerによる標準入力など）
- ファイル入出力の基礎
- 簡単なアルゴリズム練習（ソート・探索など）
